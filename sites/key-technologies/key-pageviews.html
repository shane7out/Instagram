What this report does and does not collect

Collected: page, time, the page that linked here, screen width and device type, browser language, time zone, a campaign tag if the link had one, a random tab code that is forgotten when the tab closes, how long the page was in view, how far it was scrolled, and the names of main buttons and forms. Never collected: IP address, name, email, phone, anything typed into a form, cookies, fingerprints or a permanent visitor ID. It is off for visitors who turn on Do Not Track or Global Privacy Control, and for robots.
