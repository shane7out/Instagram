The Free Website Audit tool

The audit combines Google's PageSpeed Insights scores with an automated scan of a site's public page source for PHP/WordPress signatures. It's provided for free, "as is," with no guarantee of accuracy, completeness, or availability. It is a quick, surface-level check — not a professional security audit, not a substitute for one, and not a guarantee that a "clean" result means a site is actually secure, or that a flagged result means it's under active attack.

Third-party services

Running the audit sends the URL you enter to Google's PageSpeed Insights API and to a public proxy service (api.allorigins.win) so the page can be fetched and scanned. Both are outside Key Technologies' control — if either is slow, unavailable, or returns an error, the tool will say so honestly rather than show a fake result.
