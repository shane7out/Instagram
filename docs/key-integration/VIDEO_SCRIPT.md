# Key Rewards: 2-minute video, voice-over script

Length: 2:00. Portrait, 1080 x 1920. 22 scenes: an intro card, the 20 screens of the swipe deck at keytechnologies.si/keys ("1 of 20" to "20 of 20"), and an outro card. The gold key is fixed at the top of every scene.
Words are short and plain on purpose (a 3rd grader up to a 100-year-old).
Voice (for ElevenLabs): calm, warm, friendly, not salesy. A little smile. Pause one beat between scenes.
Pace: about 130 words a minute. If a scene runs long, cut the last sentence, not the first.
